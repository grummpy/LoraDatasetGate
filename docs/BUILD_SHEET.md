# LoraDatasetGate — Build Sheet
Repo: https://github.com/grummpy/LoraDatasetGate (public). Owner: grummpy.

## Purpose
One CPU-only app that checks a LoRA training dataset before training. Point it at a folder (subject images, optional reg/class folder, caption .txt files). It NEVER queues GPU jobs and NEVER contacts ComfyUI (no network calls except localhost UI; add a test asserting no outbound sockets).

## Modules
1. **NearDupLens** — pHash/dHash (imagehash) + CPU embedding similarity (open_clip ViT-B-32 on CPU, optional; fallback to color-histogram/ORB if model unavailable). Cluster near-dupes (union-find on thresholds, configurable), show groups side by side, suggest keep = highest resolution/sharpness (Laplacian variance). Export keep/drop list CSV; never delete files, only move to `_rejected/` on explicit user click.
2. **RegSetBalancer** — count subject vs regularization/class images, ratio, per-concept breakdown via captions; recommend target ratio (configurable default 1:1 to 1:2 reg per subject × repeats) and number to add/remove.
3. **PoseCoverageMap + AspectBucketPlanner** — CPU face/pose landmarks (mediapipe or OpenCV DNN) to estimate head yaw/pitch bins (front, 3/4 L/R, profile L/R, up/down) and framing (close-up/half/full by face-to-frame ratio). Aspect ratio → SDXL/SD1.5 bucket list. Heatmap grids (pose × framing, bucket counts) with gaps highlighted and "add N images of X" suggestions.
4. **FaceCropGate** — detect faces, propose crops; every crop shows in an approval queue (Approve / Reject / Re-crop). Export to training set ONLY for approved crops. Append-only approval log `gate_log.jsonl` (timestamp, file, crop box, hash, decision). Export button disabled while any crop pending.

## UI
Tabs: Dataset · Duplicates · Balance · Coverage · Face Gate · Report. One-click "Run all checks" → HTML/JSON report.

## Synthetic sample data
`samples/` generated by `scripts/make_samples.py`: geometric shapes, near-dup variants (resize/jpeg/crop), simple cartoon "face" drawings (circles/ellipses) with synthetic pose labels for tests. No real people.

## Tests
Hash grouping finds planted dupes; ratio math; bucket assignment; heatmap gap detection; gate blocks export of unapproved crops; log is append-only; no-network test.
